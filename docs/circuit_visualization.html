📊 Mathematical Foundation

The circuit proves the following zero-knowledge relation:

R = {(h, pp) ; (P, a, p, r) : C(P, (a, p)) = 1 ∧ Com(P; r) = h ∧ ∀j ∈ [M] : VerifyPredicate(pj, ppj) = 1}

Where:

  • h: Policy commitment (public)
  • pp: Public parameters for predicate verification (public)
  • P: Privacy policy in RPN format (private)
  • a: Requester attributes (private)
  • p: External predicate values (private)
  • r: Commitment randomizer (private)

💡 Example Policy Evaluation

Policy: "attribute₀ AND attribute₁"

RPN Encoding:
[0, 1, 5, 0, 0, 0, 0, 0, 0, 0]
• 0: Push attribute₀
• 1: Push attribute₁
• 5: AND operation (N+M+0)
• 0...0: Padding
Evaluation:
Stack: [] → [a₀] → [a₀,a₁] → [a₀∧a₁]
Result: Access granted if both
attribute₀=1 AND attribute₁=1

🔐 Privacy & Security Properties

Privacy Guarantees

  • Policy Privacy: Actual rules never revealed
  • Attribute Privacy: Individual attributes remain private
  • Zero-Knowledge: Only satisfaction is proven

Security Properties

  • Completeness: Valid witnesses always succeed
  • Soundness: Invalid witnesses cannot produce valid proofs
  • Knowledge Soundness: Prover must "know" the witness
